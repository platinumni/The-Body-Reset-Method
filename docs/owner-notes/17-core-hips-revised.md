# Core & Hips: revised order (owner direction, 2026-10-24): HIPS FIRST, then core, then culmination. Build at CH.
Owner points:
- 90/90: push up off the knuckles first and let the body relax into it.
- Hip CARs: no leaning; keep the circles smaller and build range off the correct pattern.
- Step hip up/down: hip hikes (hip hitch / pelvic drop) on a step, for hip control.
- Leg swings, including 360.
- Basic hip stretches and openers. Each with a basic and an advanced version.
- Strengthening: advanced versions with resistance bands and weights.
- "Building range of movement off the correct pattern." Philosophy and balance first.

1. 90/90 hip switches
2. Hip CARs
3. Leg swings

6. Adductor rock-backs
